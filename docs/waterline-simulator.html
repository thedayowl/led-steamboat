How it works

Each LED gets a number from three sine waves added together. Each wave has its own length and speed, so the pattern never repeats exactly. Crests turn pale, troughs go deep navy.

The sum (−2.1 to +2.1) is mapped through four blues, darkest to lightest. It's biased toward the dark end (raised to the power 1.4), so pale caps are rarer, like light catching the odd wave.

Position comes from the order the runs are listed, not the LED numbers. So the water still flows smoothly when a section is wired in pieces or backwards. rev flips the direction; the speed setting scales the clock.
